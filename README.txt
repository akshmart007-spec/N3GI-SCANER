N3GI SCANER v1.2 — APK kaise banayein (Android Studio ke bina)

1. GitHub par naya repository banao.
2. Is ZIP ke saare files upload karo (.github folder bhi).
3. Actions > "Build APK" > Run workflow.
4. Artifacts se app-debug.apk download karke install karo.

App features:
• Google native barcode / QR scanner
• Fast continuous autofocus + tap-to-focus
• Photo stamp: BARCODE | Photo 1/2 | DD-MM-YYYY HH:MM:SS
• ZIP: Photos/{barcode}/{barcode}_1.jpg structure
• PDF: 1 photo per full page
• Native share (photo, ZIP, PDF → WhatsApp / Drive / etc.)
• Session / batch name in file names
• Undo last photo, Rescan shortcut
• Keep screen on while camera open
• Remove mode + notes + CSV
• Dark / light theme, beep + strong haptic
